# Source feasibility and boundaries (2026-11-16)

| Source | Useful data | Permission/quality conclusion |
|---|---|---|
| Wikidata | Stable MAL links, structured statements, revision IDs, qualifiers, references | CC0; existing bounded collector enabled. Community assertions often lack adaptation and recurrence evidence; never enough alone for approval. |
| AniList | Character identities/names/descriptions and media relations | Official API terms prohibit mass collection/hoarding/storage and require commercial permission in specified circumstances. No bulk integration enabled. Character prose is not a verified trait schema. |
| AniDB | Potential character tags and identities | Official API/policy pages returned access restrictions during investigation. Licensing and redistribution not verified; no collector enabled. |
| Jikan / MAL | Character identities, aliases and descriptive material | Maintainer announced public Jikan API discontinuation on 2026-10-01. Self-hostable scraper code does not grant rights to underlying MAL data; no new dependency enabled. |
| Kitsu | JSON:API character/media relationships | Public API documentation is not a redistribution license. Trait reliability and bulk reuse permission unresolved; no collector enabled. |
| Anime Characters Database | Community appearance and identity tags | No authoritative bulk API/reuse permission established in this review; no collector enabled. |
| Official studios, broadcasters, publishers, licensed distributors | Character and episode facts tied to specific adaptations | Used as individually inspected links and short factual summaries. Not a general license to crawl, copy biographies/images, or redistribute datasets. |

Pilot evidence includes GKIDS and Disney Japan film synopses; YTV Conan profiles;
Apple TV's original Ouran episode 24 synopsis; the official Frieren Heiter profile;
and the original ARIA episode guide. Dengeki's Hime retrospective and a regional
Monster episode listing remain secondary evidence. Their URLs, access dates, factual
summaries, adaptation bindings and evidence hashes are in the private review state.

Two separately written licensed synopses support the Jiji species claim. Their different
publishers alone do not establish independence; origin-family classification remains a
reviewable provenance assertion. If an underlying syndicated origin is discovered,
merge the families and the candidate loses batch status. Richard's syndicated-looking
secondary listing is not counted as independent official corroboration. Unrelated
live-action Monster and King of Fighters search matches were excluded.

No source here authorizes redistribution of the existing catalogue's entire imported
corpus. That prior licensing blocker remains. Links and limited factual extraction do
not remove it. Do not publicly host private snapshots or review exports.
